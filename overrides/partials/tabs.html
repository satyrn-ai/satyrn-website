{#- The tab bar. Replaces the theme's partial, which loops `nav.items` and so renders every top-level section in whatever order the directory walk produced. Here the bar is `extra.nav_tabs` instead: an ordered, editorial list. Each entry still resolves against `nav.items` rather than carrying its own URL, so the link, the trailing slash and the active state all stay the theme's job and cannot drift from where the page actually lives. An entry naming a page that does not exist renders nothing and does not fail the build. `just check-nav` compares the built bar against this list. -#}
